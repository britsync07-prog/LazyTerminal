# LazyTerminal Android App

This is the Android mobile client for LazyTerminal, built with React Native, Expo, and TypeScript.

## Status: Scaffolded (Task 001)

In Task 001, the repository foundation and Windows PTY proof-of-concept are established.
The full mobile application—including local connection management, multi-tab terminal switching, xterm.js rendering in WebView, and touch control toolbar—will be implemented in Milestone 2.
